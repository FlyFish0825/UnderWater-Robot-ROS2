话题、服务与自定义消息总线

本系统的所有业务逻辑通过 ROS 2 标准的发布/订阅（Pub/Sub）与请求/响应（Service Client）架构实现解耦。系统统一运行在 /underwater_robot 命名空间下。

1. 核心话题矩阵 (Topics Reference)

话题名称 消息类型 典型发布频率 详细说明
/underwater_robot/sensors/imu/state underwater_interfaces/ImuState 20 ~ 50 Hz 包含线加速度 (m/s²)、角速度 (rad/s)、四元数、欧拉角 (度)、气压组及有效位掩码
/underwater_robot/sensors/depth/state underwater_interfaces/DepthState 约 25 Hz MS5837 实测压力 (Pa)、水温 (°C)、计算水深 (m)、水面参考基准 P0 (Pa)、高位错误诊断码
/underwater_robot/actuators/thrusters/state underwater_interfaces/MotorState 10 ~ 20 Hz 8 路推进器实时遥测：实际转速 (RPM)、母线电压 (V)、母线电流 (A)、电调温度 (°C)
/underwater_robot/control/allocation_status underwater_interfaces/AllocationStatus 10 Hz 动力分配状态：期望的六轴力、实际分配的八路目标 RPM、OSQP 求解残差、是否进入死区
/underwater_robot/control/manual_request geometry_msgs/Twist 10 Hz 键盘手动输入的六轴目标档位（x, y, z 分别为纵向/横向/垂向，angular.z 为偏航航向）
/underwater_robot/control/motor_command underwater_interfaces/MotorSetpoint 10 Hz 最终下发给 8 台电机的目标转速向量与运行使能掩码
/underwater_robot/global_camera/left/image_raw sensor_msgs/Image 25 ~ 30 Hz 左目 1280x720 BGR8/RGB8 原始图像数据，供 SLAM/目标识别订阅
/underwater_robot/global_camera/right/image_raw sensor_msgs/Image 25 ~ 30 Hz 右目 1280x720 BGR8/RGB8 原始图像数据，供立体视差匹配计算

2. 核心服务接口 (Services)

服务名称 服务类型 功能与调用条件
/underwater_robot/control/enable std_srvs/SetBool 电机动力启停使能。仅当 data=true 且 Orin NX 持有控制权时，推进器才被允许下发物理转速。发 false 立即全停。
/underwater_robot/sensors/depth/zero std_srvs/Trigger 深度水面归零。机器人置于水面静止时调用，采集连续有效压力更新水面基准大气压 $P_0$，重设水深 $0.00\,\text{m}$。
/underwater_robot/sensors/imu/calibrate underwater_interfaces/CalibrateImu IMU 姿态相对基准校准。采集当前静止姿态作为参考基准，后续输出相对于此基准的水平平放或指定朝向。
/underwater_robot/gateway/control_ownership underwater_interfaces/ControlOwnership 控制权切换仲裁。用于查询或在上位机 GUI（CLAIM GUI）与机载 ROS 2（CLAIM NANO）之间原子交接控制权。

3. 自定义消息 (IDL Messages) 字段深度拆解

ImuState.msg
std_msgs/Header header
geometry_msgs/Vector3 linear_acceleration  # m/s^2
geometry_msgs/Vector3 angular_velocity     # rad/s
geometry_msgs/Quaternion orientation       # 四元数
float64 roll                               # 横滚角 (度)
float64 pitch                              # 俯仰角 (度)
float64 yaw                                # 偏航角 (度)
float64 pressure                           # 气压 (Pa)
uint32 validity_flags                      # 有效性掩码位
DepthState.msg
std_msgs/Header header
float64 depth           # 计算水深 (米, m)
float64 temperature     # 水温 (摄氏度, °C)
float64 pressure        # 实测绝对压强 (Pa)
float64 surface_p0      # 当前采用的水面大气压基准 (Pa)
bool is_valid           # 深度数据有效性
uint32 status_flags     # MS5837 状态机高位诊断错误码
MotorState.msg
std_msgs/Header header
int16[8] rpm            # 8 路推进器当前实时转速
float32[8] voltage      # 各路母线电压 (V)
float32[8] current      # 各路母线电流 (A)
float32[8] temperature  # 各路电调/MCU 温度 (°C)
bool[8] online          # 8 个 CAN 节点在线状态
AllocationStatus.msg
std_msgs/Header header
geometry_msgs/Wrench requested_wrench # 期望力与力矩
float64[8] allocated_thrust          # 各路计算推力 (N)
int16[8] target_rpm                  # 最终映射目标转速
bool in_deadzone                     # 是否落在死区内停机
uint32 osqp_iterations               # QP 求解器迭代次数
