常见故障排查手册 (FAQ)

本手册汇总了水下机器人实机测试与调试过程中最容易遇到的高频硬件、网络与权限问题，帮助初学者快速排障：

❓
问题 1：启动提示找不到串口 /dev/ttyACM0 或 Permission denied

原因: USB 数据线松动、未识别，或当前 Linux 用户没有 dialout 串口访问权限。
解决步骤:
1. 运行 ls -l /dev/ttyACM* 查看设备节点是否存在；
2. 运行 sudo usermod -aG dialout $USER 将当前用户加入串口组，重新注销登录生效；
3. 检查是否有旧进程占用串口：fuser -v /dev/ttyACM0，杀掉残留进程。

❓
问题 2：IMU 数据有效位显示 0，读数全部为 0 或卡死

特别注意（实机血泪经验）: 如果控制板上还插着 WCH-Link 下载调试器，WCH-Link 的引脚电平会干扰板载 IMU 串口通信！进行 IMU 验收和正常作业前，必须拔下 WCH-Link 下载器，重启下位机即可恢复。

❓
问题 3：键盘有输入，但推进器完全不转动

排查顺序:
1. 检查启动时是否指定了 motor_tx:=true（默认出于安全考虑是 false 关闭电机输出的）；
2. 检查推力是否落入了 1000 RPM 死区（输入力微小时，系统自动截断为 0 保护电机）；
3. 检查控制权是否被上位机 GUI 占用（若处于 STATE GUI，机载 ROS 指令被硬件锁死拒绝）。

❓
问题 4：上位机连接 TCP 9000 或 9001 报 Connection Refused

解决步骤:
1. 检查 Orin NX 与上位机是否处于同一网段（例如 Orin NX 为 192.168.20.70）；
2. 检查节点是否已正常启动（运行 ss -tuln | grep -E '9000|9001|9002' 确认端口已处于 LISTEN 状态）；
3. 确认 Ubuntu 防火墙未阻断端口（sudo ufw status）。
