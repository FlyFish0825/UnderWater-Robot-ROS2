教程 1：环境搭建与全量编译

本项目在 Jetson Orin NX 16GB Super（Ubuntu 22.04 + ROS 2 Humble）实机环境验证通过。请按如下标准步骤操作：

步骤 1：确认操作系统与 ROS 2 Humble 环境

打开终端，执行以下命令确认 ROS 2 基础环境已就绪：

BASH
source /opt/ros/humble/setup.bash
ros2 --version # 应输出 ros2 cli 版本
步骤 2：进入工作空间并执行一键编译

项目根目录下已配置 colcon_defaults.yaml，自动设置构建参数，直接运行：

BASH
cd /home/lamost/UnderWater-Robot-ROS2
colcon build
source install/setup.bash

💡 构建系统会自动逐包构建 13 个项目包，启用 --symlink-install 符号链接安装与 RelWithDebInfo 优化等级。

步骤 3：核对编译产出
BASH
colcon list # 应列出全部 13 个包且状态正常

教程 2：日常开机与传感器监视

当下位机 MCU 通过 USB 插入 Jetson Orin NX 时，最常用的操作是查看传感器状态并验证硬件连线：

BASH - 终端 1：启动传感器底层后台
cd /home/lamost/UnderWater-Robot-ROS2
source /opt/ros/humble/setup.bash
source install/setup.bash

# 启动串口网关与传感器解析节点（默认只读监听，不驱动电机）
ros2 launch underwater_bringup base.launch.xml
BASH - 终端 2：多传感器实时汇总查看
source /opt/ros/humble/setup.bash
source install/setup.bash

# 运行传感器汇总终端，打印 IMU 姿态、温度、深度与压力
ros2 run sensors_cpp sensors_sub
🌊
水面深度一键归零技巧

若下水前因当天天气气压波动，深度读数不为 0（如显示 0.05m），在机器人平放于水面时执行：
ros2 service call /underwater_robot/sensors/depth/zero std_srvs/Trigger
系统将自动采样当前大气压作为新的 $P_0$ 零点，立即归零！

教程 3：双目相机与网络推流

系统配备 720P 双目 USB 相机。启动后，Orin NX 节点不仅发布左右目 ROS 话题，还会开启 TCP 9001 供上位机拉流：

BASH - 启动双目相机采集与推流
source /opt/ros/humble/setup.bash
source install/setup.bash

# 启动全局双目相机节点
ros2 launch global_camera stereo.launch.xml

上位机 (Windows/Qt) 接入指南：上位机通过 Socket 连接 192.168.20.70:9001。协议数据帧格式为 4 字节魔数 0xAA 0xBB 0xCC 0xDD + 4 字节数据长度 (大端) + JPEG 原始二进制字节流，直接通过 OpenCV cv::imdecode 即可解出彩色图像。

教程 4：键盘安全控制与隔离预览

🛑
安全第一法则：先预览，后使能！

在没有放入测试水池、或者没有接水下电机的空载陆上调试时，强烈建议开启 preview 隔离预览模式！预览模式下可以正常观察键盘按键对六轴力矩、推力分配与目标 RPM 的计算，但绝对不会向下位机发送实际转动指令。

BASH - 终端 A：启动带控制栈的后台（关闭实际电机发送）
# motor_tx:=false 保证硬件电机不会转动
ros2 launch underwater_bringup manual.launch.xml motor_tx:=false
BASH - 终端 B：启动手动键盘控制
ros2 run manual_control manual_control --ros-args -p auto_start:=false -p preview:=true

键盘操作键位映射速查表

按键 (Key) 控制自由度 动作效果
W / S$F_x$ 前进 / 后退推进器 fan1~4 协同产生纵向推力
A / D$F_y$ 左移 / 右移推进器 fan1~4 协同产生横向推力
I / K$F_z$ 上浮 / 下潜垂直推进器 fan5~8 协同产生升沉推力
J / L$M_z$ 左转 / 右转 (偏航 Yaw)水平推进器差速产生回转力矩
Space (空格)急停六轴力矩瞬间清零，推进器停转

教程 5：上位机 GUI 与控制权协同

本项目支持 PC 端 Underwater_GUI 与板载 Orin NX 双模工作。通过独占控制权协议，彻底解决“上位机操作手与机载自动算法争夺电机”的工业难题：

1
握手连接建立 STATE NANO
上位机 TCP 9002 连接 Orin NX 时，Orin NX 立即回复 STATE NANO。此时控制权属于板载端，上位机初始为只读模式，可监视传感器，但不能向串口发送电机指令。
2
上位机申请接管 CLAIM GUI ➔ OK GUI
操作手在 GUI 界面点击“接管控制权”，GUI 发送 CLAIM GUI。Orin NX 立即停用本地 ROS 2 电机下发并返回 OK GUI。此时上位机获得独占写入权，可经由 TCP 9000 下发原始电机控制指令。
3
释放控制权与断网保护 RELEASE GUI ➔ STATE NANO
操作手点击“释放控制权”（发送 RELEASE GUI）或当网络发生中断时，Orin NX 控制权看门狗自动触发急停保护，安全复位为 STATE NANO，恢复板载控制。

教程 6：10Hz 数据落盘与分析

水下试验最宝贵的就是实验数据。系统内置了开箱即用的 10Hz 高速 CSV 记录工具：

BASH - 启动全量数据记录
# 启动记录工具，默认自动保存至工作空间 Recodes/ 目录
ros2 run sensors_cpp sensors_sub_jilushuju

输出 CSV 字段格式：时间戳, 水深(m), 水温(℃), 压力(Pa), 加速度X, 加速度Y, 加速度Z, 角速度X, 角速度Y, 角速度Z, 欧拉角Roll, 欧拉角Pitch, 欧拉角Yaw, 深度有效位, IMU有效位。缺测或传感器离线字段自动填入 NaN，不伪造数据，可直接导入 MATLAB 或 Python Pandas 进行绘图与动力学辨识分析。
