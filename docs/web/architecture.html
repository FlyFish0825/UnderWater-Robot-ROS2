系统分层架构与数据流

本项目严格遵循现代机器人系统的关注点分离（Separation of Concerns）原则，从物理硬件到顶层应用分为五个清晰层次。各层之间通过标准化的 ROS 2 话题、服务或 TCP 套接字松耦合互联，保证单层升级不影响全局稳定性：

🖥️ 顶层人机交互与外部应用
Layer 4: Application & UI
Windows / Linux Qt 上位机
Underwater_GUI：TCP 9000 原始数据透传、TCP 9002 控制权请求与状态握手、3D 姿态与仪表盘显示。
ROS 2 键盘操作 / 自动化脚本
终端键盘六轴手动控制、Forces 激励时序发生器、自主巡航任务状态机。
↕ 通信通道： TCP 9000 (原始字节) | TCP 9002 (控制权仲裁) | TCP 9001 (双目 JPEG 流) | ROS 2 话题总线
📦 Orin NX: 业务与外设兼容层 (src/)
Layer 3: User & Peripheral
sensors_cpp 兼容层
复刻原 14 个兼容命令分派、sensors_sub 汇总查看、sensors_sub_jilushuju 10Hz CSV 实时落盘。
manual_control 控制交互
终端键盘六轴档位输入解析、forces 时序激励发生、preview 隔离预览安全门禁。
global_camera 双目视觉
V4L2 双目图像采集驱动、左右目画面实时拆分发布、内置 TCP 9001 JPEG 压缩推流服务。
↕ 内部 ROS 2 话题总线： /underwater_robot/ (ImuState, DepthState, MotorState, AllocationStatus, manual_request)
🧠 Orin NX: 核心算法与设备层 (internal/)
Layer 2: Algorithms & Core
underwater_control 动力分配
基于 OSQP 二次规划的最优推力分配算法、thruster_center 几何中心力矩计算、1000~6000 RPM 死区与极性映射。
underwater_devices 设备抽象
MS5837 深度状态机与水面归零服务、IMU 姿态相对基准校准、0x201..0x208 电机遥测解析。
underwater_description 机器人模型
北东地 (NED) 坐标系 URDF 刚体模型、base_link 到 thruster_center 静态 TF 变换。
↕ 内部数据流： gateway/frames (AA55/58/5B 解码帧) | gateway/status (网关遥测) | 下行电机控制报文
🔌 Orin NX: 通信网关层 (underwater_mcu_gateway)
Layer 1: Gateway & Protocol
串口底层驱动
带超时检测与自动重连的 USB CDC 虚拟串口（/dev/ttyACM0）驱动，波特率 921600。
增量解包状态机
64KB 环形缓冲区、AA55 (CAN/电机)、AA58 (网关状态)、AA5B (传感器遥测)、单调滑动重同步机制。
网络转发与控制权仲裁
TCP 9000 原始串口透明桥接服务、TCP 9002 独占控制权状态机（Orin NX 与 GUI 互斥）。
↕ 物理接口： USB CDC 虚拟串口数据线 (921600 Baud, /dev/ttyACM0)
⚙️ 下位机嵌入式硬件 (MCU)
Layer 0: Microcontroller
STM32H750 主控 MCU
负责高频硬件中断、看门狗安全定时器、串口协议帧封装下发。
I²C & 串口传感器
MS5837-02BA 耐压水深计（I²C 约 25Hz 采样）、高精九轴姿态 IMU 模块。
8 路 CAN 电机驱动
CAN 总线连接 8 台水下推进器 (fan1 ~ fan8)，实时反馈转速、电压、电流和温度。

源码目录与 13 包全景矩阵

工作空间分为两大源代码目录：src/（对外开放业务接口与外设包）和 internal/（核心驱动、设备模型、分配算法与接口包）：

包名 (Package) 目录路径 语言 核心职责与定位
underwater_mcu_gateway internal/ C++17 MCU 物理串口驱动、AA55/58/5B 流式增量解包、TCP 9000 透明转发、TCP 9002 独占控制权管理
underwater_devices internal/ C++17 设备语义建模。将底层网关字节帧转化为标准的 IMU、深度计、电机状态 ROS 消息；水面零点与基准标定
underwater_control internal/ C++17 六自由度动力分配（基于 OSQP 二次规划求解器）、八推进器安装坐标力矩计算、电机死区与极性映射、安全启停控制
underwater_description internal/ URDF/XML 机器人 3D 几何与刚体模型。严格定义 NED 坐标系下 base_link 到 thruster_center 的静态 TF 变换
underwater_bringup internal/ XML/Launch 顶层 Launch 启动集合：base.launch.xml、manual.launch.xml、tcp.launch.xml 等
underwater_interfaces internal/ IDL 核心消息与服务接口定义：ImuState, DepthState, MotorState, AllocationStatus, ControlOwnership
underwater_robot internal/ C++17 顶层系统级节点与生命周期整合
sensors_cpp src/ C++17 兼容层核心。复刻原 14 个 Python 命令名（如 sensors_sub, sensors_sub_jilushuju 10Hz CSV 录制），提供共享后端 compat_runtime
manual_control src/ C++17 手动控制兼容包。终端键盘六轴输入、时序激励生成（forces_pub）、时间测试与预览隔离
global_camera src/ C++17 双目相机采集驱动。V4L2 硬件配置、左右目图像实时拆分、ROS sensor_msgs/Image 发布、TCP 9001 JPEG 推流
msg_pkg src/ IDL 历史消息接口兼容包，提供 ImuData.msg, DepthSensor.msg, Forces.msg 等
imu_py src/ C++17 保留原 imu_publisher 命名与使用习惯的轻量入口
depth_py src/ C++17 保留原 depth_publisher 命名与使用习惯的轻量入口
