八推进器动力分配 (QP Allocation) 深度解析

机器人六自由度运动（前/后 $F_x$、左/右 $F_y$、上/下 $F_z$、横滚 $M_x$、俯仰 $M_y$、偏航 $M_z$）由 8 台推进器协同驱动。由于推进器数量（8）大于受控自由度（6），该系统属于过驱动系统（Over-actuated System）。本项目采用基于 OSQP 的二次规划算法进行最优推力分配。

📌
力矩基准：thruster_center

本系统严格以 8 台推进器安装坐标的算术平均中心作为力矩基准点，其相对于 URDF 原始 base_link 原点的平移量为：
r_offset = (-0.012873, 0.0, -0.040532) m。 所有推进器的位置矢量在分配计算前均统一减去此偏移量，消除绕底部原点计算带来的虚假俯仰/横滚力矩耦合！

二次规划数学模型与源码核心逻辑

动力分配的目标函数综合考虑期望力跟踪误差最小化与推进器功耗能量最小化：

C++ 核心代码：OSQP 矩阵装配与求解 
// internal/underwater_control/src/allocation/thrust_allocator.cpp
// 构建推力配置矩阵 B (6x8): 每一列为推力单位向量与安装位置的力矩叉乘
for (int i = 0; i < 8; ++i) {
    Eigen::Vector3d r = positions[i] - thruster_center_; // 消除原点偏移
    Eigen::Vector3d d = axes[i];                          // 单位推力方向
    Eigen::Vector3d m = r.cross(d);                       // 力矩: r x d
    B.block<3, 1>(0, i) = d; // 线性力 (Fx, Fy, Fz)
    B.block<3, 1>(3, i) = m; // 力矩   (Mx, My, Mz)
}

// 二次规划目标函数: min 0.5 * u^T H u + g^T u
// H = 2 * (B^T * W_v * B + W_u),  g = -2 * B^T * W_v * F_desired
// 约束: u_min <= u <= u_max (推力上下界限幅)
solver.updateHessianMatrix(H_sparse);
solver.updateGradient(gradient);
solver.solveProblem();
Eigen::VectorXd thrust = solver.getSolution();

// 死区与电机方向映射计算:
for (int i = 0; i < 8; ++i) {
    double raw_rpm = (thrust[i] / nominal_max_thrust_N) * max_rpm; // 线性推力-转速映射
    if (std::abs(raw_rpm) < 1000.0) {
        final_rpm[i] = 0; // 落在死区内停机，防止电机低频啸叫或发热
    } else {
        double clamped = std::clamp(std::abs(raw_rpm), 1000.0, 6000.0);
        final_rpm[i] = std::copysign(clamped, raw_rpm) * motor_direction[i];
    }
}

底层串口流式增量解析机制

机器人通过 USB CDC 虚拟串口以 921600 波特率高速传输二进制数据。工业现场中经常面临网络扰动、USB 中断重连、操作系统缓冲区粘包与分片等问题。本项目设计了有界增量流式解析器（Incremental Streaming Parser）。

AA55 帧族（CAN 与电机数据）
格式: AA 55 [BODY_LEN:u8] ... [CRC8:u8] 55 AA
校验: CRC-8 (多项式 0x07, 初始值 0x00)。覆盖从长度字段到尾部前的全部字节。
语义: 承载 CAN 节点反馈（0x201..0x208 电机状态）与下发电机指令（0x100 速度向量、0x11 运行掩码）。
AA58 帧族（网关遥测与流控）
格式: AA 58 ... [CRC16:u16] (总长 20+N 字节)
校验: CRC-16/CCITT-FALSE (多项式 0x1021, 初始值 0xFFFF，小端)。
语义: 汇报 MCU 内部输入/输出 FIFO 队列占用率、CAN RX/TX 负载和硬件状态。
AA5B 帧族（高精传感器遥测）
格式: AA 5B [VERSION=1] [TARGET] [CMD] ...
子命令:
  • 0x80: IMU 原始角速度与加速度 ADC
  • 0x81: IMU 融合姿态欧拉角与状态位
  • 0x82: MS5837 压力与温度数据
  • 0x83: 深度计状态机与 I²C 阶段诊断
  • 0x85: 固件气压组（高度、参考气压、气压值）
⚠️
防粘包与单调重同步原则

若遇到数据截断或校验失败，解析状态机绝不丢弃整个缓冲区，而是将滑动游标仅向后递增 1 字节重新寻找下一个候选帧头（AA 55 / AA 58 / AA 5B）。环形缓冲上限严格锁死在 65536 字节，半包等待超时设为 1.0 秒，彻底杜绝内存泄漏与死锁卡死。
