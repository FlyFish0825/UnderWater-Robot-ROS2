## C++ 伪终端完整链路

测试程序 tests/integration/serial_control_probe.cpp：
启动真实网关、设备和分配节点，连接专用 POSIX PTY，不打开机器人真实串口。
ROS_DOMAIN_ID=190，仅本机，命名空间带本次进程编号。
向 PTY 输入模拟网关心跳，向分配节点输入 WrenchStamped，再从 PTY 另一端解析实际写出的 AA55。

本轮结果：
- 捕获 988 个完整电机命令帧，其中 RUN 停机帧 321、非零 RUN 帧 173。
- Fz=400，其余为0：RPM=[0,0,0,0,1242,1242,1158,1158]。
- 未 enable 时，没有非零运行帧。
- enable 后，速度和运行向量确实到达串口端点，所有值满足0或±1000..6000。
- 停止六轴输入后，发送 RUN_VECTOR(RunMask=0)，控制节点取消启用。
- 恢复输入不自行启动；显式重新 enable 后才恢复输出。
- 关闭并重建 PTY 后，网关重连并改变 connection_id，旧转速没有恢复，保持停机和未启用。
- 测试子进程退出，临时 PTY 清理。此验证不等于 CAN 总线应答或真实电机旋转。
